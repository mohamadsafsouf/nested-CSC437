CamGuard Web Attack Simulator

Safe local tests only. The CamGuard Mac app listens on 127.0.0.1:39452 for a silent POST /camguard/v1/hint (JSON {"host":"…"})—no “open app?” dialog. If the app is not running or the port is blocked, the page falls back to camguard:// (Safari may prompt). FastAPI dummy-upload is separate metadata for the backend. Serve this folder at http://localhost:3000/camera-upload-test/ and use query ?hintPort=39452 if you change the port.

Backend required for tests 3 and 4. From the backend/ directory, with a valid .env, run: uvicorn app.main:app --host 127.0.0.1 --port 8000 (port is 8000, not 800). If you use ?api=, use http://127.0.0.1:8000 with four digits.
